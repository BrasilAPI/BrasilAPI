## 🔴 Achados críticos

### 1. Docs OpenAPI = 60% do código e DESATUALIZADAS (prioridade máxima)
O JSON de spec é o maior artefato do repo, mas a paridade **rota real ↔ doc** está quebrada:

**26 rotas reais SEM documentação nenhuma:**
- `fipe/*` completo (marcas, preco, veiculos, anos, detalhes)
- `ibge/cnae/*`, `ibge/municipios/v1/{uf}`, `ibge/regioes/*`, `ibge/uf/v1/regiao/*`
- `ibpt/*` completo (ncm, nbs, lc116)
- `cptec/v1/cidade/{name}`, `cptec/v1/clima/aeroporto/{airport}`
- `oms/cid10/v1` (+`/{code}`), `solar/v1`, `status/v1`, `indices/codes`, `feriados/v1`

**~10 rotas com param names divergentes** (doc em PT-BR, código em EN):
| Doc diz | Código usa |
|---|---|
| `/fipe/marcas/v1/{tipoVeiculo}` | `{vehicleType}` |
| `/ibge/cnae/v1/classes/{codigoClasse}` | `{classe}` |
| `/ibge/municipios/v1/{siglaUF}` | `{uf}` |
| `/cptec/v1/clima/aeroporto/{icaoCode}` | `{airport}` |
| `/ibpt/ncm/v1/{siglaUF}` | `{uf}` |

**Outros problemas de doc:**
- `eleicoes.json` usa prefixo `/api/` nos paths (inconsistente com todos os outros)
- `solarIncidence.json`: path `/solar_incidence/v1/{location}` mas a rota real é `/solar/v1` — **rota renomeada sem doc**
- `holydays.json`: só documenta `/feriados/v1/{ano}`, falta `/feriados/v1` (sem ano) e o novo param `uf` foi adicionado por mim hoje
- `status.json` não existe (endpoint `/status/v1` sem doc)

**Causa raiz**: os rebases (#861–#876) trouxeram endpoints novos com docs do autor original que usavam nomes PT-BR, mas o código da main usa EN — a doc NÃO foi adaptada. O teste `docs-spec-refs.test.js` (criado hoje) só valida refs, não a paridade de rotas/params.

### 2. Lint global com 43 erros que o CI não pega
- `util/mapUfToUfCode.js`: **42 erros prettier** (aspas duplas em vez de simples) — introduzido sexta (#811/#820)
- `services/cptec/weather.js`: 1 erro prettier
- `pages/api/cpf/v1/[cpf].js` + `util/cep-error-handler.js`: 3 warnings `no-console`
- **O CI E2E só roda `npm test` — nunca roda lint!** Os erros existem desde sexta e ninguém viu.
- ⚠️ `npm run fix` (o gate do CLAUDE.md) falharia hoje

### 3. Teste falso-positivo: `tests/ncm-v1.test.js`
- `test('Utilizando uma descrição inexistente')` faz `try { await axios.get() } catch { ... }` **sem `expect.assertions`** — se a chamada retorna 200 (como faz hoje, `[]`), o teste **passa sem validar nada**. O handler foi mudado (200 `[]` no commit 984c956) mas o teste ficou esperando 404 silenciosamente.
